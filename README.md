# «Зодиак» для Android

Самостоятельная офлайн-адаптация карточной мини-игры из W.I.T.C.H. / «Чародейки» для Windows. Интерфейс, обучение и документация — на русском. Текущая версия — **0.5.1**, `versionCode = 6`; минимальная система — **Android 8.0 / API 26**.

Приложение написано на Kotlin и Jetpack Compose. Карточные правила восстановлены по Lua установленной PC-игры и наблюдаемым игровым переходам. Десятый уровень, новая прогрессия, лёгкая и сложная стратегии — расширения Android-адаптации. Источники и степень подтверждения приведены в [исследовании](docs/RULES_RESEARCH.md) и [правилах](docs/GAME_RULES.md).

## Возможности

- Прохождение из 10 уровней с целями от 100 до 1000 очков и тремя сложностями соперницы Вилл: всего 30 испытаний.
- Бесконечная игра после побед на лёгкой сложности всех 10 уровней; очки сохраняются между розыгрышами.
- Учебная партия из 14 этапов на том же движке, что и обычная игра; обучение не меняет статистику и прогресс.
- Каталог из 36 типов карт, 48 экземпляров колоды, открытые наборы обоих игроков и пояснения действий Вилл.
- Отдельные сохранения прохождения и бесконечной игры, подтверждение замены партии, пауза и продолжение после перезапуска.
- Анимации ходов с настройкой «Меньше анимаций», две локальные музыкальные темы и звуковые эффекты.
- Портретная и горизонтальная раскладки, увеличенный шрифт и семантика для средств доступности.

Все игровые ресурсы входят в APK. Первый запуск не требует сети; в основном манифесте нет разрешения `INTERNET`. Аккаунты, сервер, реклама и аналитика не используются.

## Как играть

Начните с **«Как играть» → «Учебная партия»**. Для обычной игры откройте **«Прохождение»** и выберите доступное испытание.

1. Коснитесь карты руки, затем подсвеченной карты стола с тем же знаком. Если пары нет, выберите свободное место.
2. Откройте центральную колоду и разыграйте открытую карту по тем же правилам.
3. При новом пороге комбинации можно объявить очки и закончить розыгрыш либо продолжить с риском.
4. Собранные карты доступны через «Ваши наборы» и «Наборы Вилл».

Победа на лёгкой сложности открывает следующий уровень на лёгкой и среднюю сложность текущего. Победа на средней открывает сложную текущего уровня. Пройденные испытания доступны повторно.

В бесконечной игре нет целевого счёта и победителя сессии. После итога розыгрыша следующая раздача начинается автоматически. Пауза и выход сохраняют сессию; **«Пауза» → «Завершить игру»** с подтверждением фиксирует окончательный результат.

## Сборка и запуск на Windows

Требуется Android Studio с поддержкой используемого Android Gradle Plugin, JDK/JBR 25 и установленный Android SDK Platform 37. Для устройства достаточно API 26 или выше. Зависимости загружаются при сборке; установленная игра работает офлайн.

| Компонент | Зафиксированная версия |
|---|---|
| Android Gradle Plugin | 9.3.1 |
| Gradle Wrapper | 9.6.0 |
| Kotlin / Compose Compiler | 2.4.21 |
| Compose BOM | 2026.09.00 |
| JDK для Gradle | 25; при разработке использовался JBR 25.0.4 |
| JVM target | 17 |
| minSdk / compileSdk / targetSdk | 26 / 37 / 37 |

В модуле `app` Kotlin встроен в AGP; `game-core` использует Kotlin JVM. Версии заданы в каталоге зависимостей и конфигурации Gradle.

```powershell
git clone https://github.com/Yuunio/zodiac-android.git
cd zodiac-android
```

1. Откройте корень клонированного проекта через **File → Open** в Android Studio.
2. Укажите локальный Android SDK и JDK/JBR 25 для Gradle. Файл `local.properties` создаётся локально и исключён из Git.
3. Выполните **File → Sync Project with Gradle Files**. В модели проекта должны появиться `app` и `game-core`.
4. Выберите конфигурацию **app** и подключённый телефон либо запустите эмулятор через **Device Manager**.
5. Нажмите **Run**. Экран встроенного эмулятора доступен в **View → Tool Windows → Running Devices**.

Для командной строки задайте `JAVA_HOME` на установленный JDK/JBR 25, если он ещё не настроен:

```powershell
$env:JAVA_HOME = 'ПУТЬ_К_JDK_25'
.\gradlew.bat :game-core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

Последняя команда требует устройства или эмулятора, видимого в `adb devices`. Полученный подписанный debug-APK находится в `app/build/outputs/apk/debug/app-debug.apk`.

```powershell
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n com.example.witches/.MainActivity
```

На Linux/macOS используйте `./gradlew` с теми же задачами. Gradle Wrapper включён в репозиторий.

## Устройство проекта и сохранения

- `game-core` — чистое Kotlin-ядро: колода, правила, состояния, стратегии и учебный сценарий; без Android-зависимостей.
- `app` — Compose-интерфейс, ViewModel / StateFlow, представление анимаций, музыка и локальный DataStore.
- `docs` — исследование, правила, архитектура, проверки, происхождение ресурсов и журнал навыков.
- `tools` — локальный генератор музыки; в APK не входит.

Схема сохранения 3 хранит отдельные слоты режимов, прогресс испытаний, настройки, карты и их порядок, фазу, состояние генератора и накопительные очки. Схемы 1/2 читаются с сохранением прежней партии и настроек. Перед первой новой записью исходный файл сохраняется отдельно; повреждение, несовместимость и ошибки записи отображаются явно.

Результат учитывается один раз по ID партии. Учебные партии не меняют статистику. Логический ход завершается до анимации; соперник и экран получают представления без скрытой руки и будущего порядка колоды.

Облачное резервное копирование отключено; XML-правила исключают игровые данные из поддерживаемого переноса. Реальное поведение переноса зависит также от производителя устройства. Подробности — в [архитектуре](docs/ARCHITECTURE.md).
