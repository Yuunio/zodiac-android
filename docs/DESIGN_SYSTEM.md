# Дизайн-система v0.5.1

Раскладка партии закреплена по Y: постоянные области шапки, подсказки, поля, наборов и руки зависят только от размера окна и масштаба шрифта. Общей вертикальной прокрутки игры нет; рука прокручивается горизонтально. Длинные сообщения и крайние значения счёта доступны через собственную прокрутку, подробности наборов — в диалогах. Итог бесконечного розыгрыша использует область подсказки. Две колонки включаются при ширине >660dp либо ширине больше доступной высоты. Полный контракт и ограниченные подписи низких карточек описаны в [DESIGN.md](../DESIGN.md#неподвижная-раскладка-в051).

Основное решение и маршруты экранов описаны в [DESIGN.md](../DESIGN.md). Палитра определена в `ui/ZodiacApp.kt` и передана MaterialTheme; реальные карты рисует `MatchScreen.kt`, каталог — `CardCatalog.kt`, знаки — `ZodiacSymbols.kt`. Это нативный Android / Jetpack Compose, без веб-ресурсов.

В0.5 те же токены применены к списку10уровней и выбору сложности. Состояния испытания обозначены словом, а выбранная сложность — доступным `selected`. Длительности движений и поведение уменьшенной анимации определены в DESIGN.md; отдельной противоречащей палитры/шкалы не создаётся.

## Карты и типографика

Сохраняются статичный авторский звёздный фон, золотые рамки и локальный serif с кириллицей. Заголовок меню — 44 sp, заголовки экранов — 24 sp, длинный текст — 16/24 sp, фазовая подсказка — 14 sp, пояснение Вилл — 12 sp. Миниатюра игровой карты использует имя знака 10/11 sp и категорию/чародейку 8/9 sp; полные сведения доступны в диалоге. Маленькая подпись не является единственным носителем смысла: карта имеет полное доступное имя.

12 собственных векторных контуров воспроизводят общепринятые знаки зодиака U+2648–U+2653. Они рисуются из локальных путей, а не зависят от наличия символа в системном шрифте. Для каждой записи Sign есть контур; код проверяет непустые границы в квадрате 100×100. Категория определяется ядром и показывается цветом/текстом. Оригинальные портреты, музыка, текстуры и исходные Lua в APK не копируются.

CardCatalog показывает 36 разных типов из 48 экземпляров. Дубли простых знаков не занимают дополнительные ячейки. Выбор, снятие выбора и подробности работают с реальным Deck; прежние девять художественных образцов больше не открываются маршрутом «Посмотреть карты». Фильтра категорий в каталоге пока нет.

## Размеры и раскладка

Размеры ниже соответствуют текущим Compose-компонентам. `scale` означает `fontScale.coerceIn(1f, 2f)`; сам системный шрифт не уменьшается.

| Токен/компонент | Реализация v0.3 |
|---|---|
| Стол | 5×3; центр — колода, остальные 14 позиций — карты; при переполнении добавляется ряд |
| Боковой отступ игрового экрана | 12 dp |
| Промежутки стола | 5 dp |
| Карта стола | Пропорция ширина/высота `0,72 / scale`, скругление 8 dp |
| Рамка карты | 1 dp Line; при выделении 2 dp Gold |
| Учебная карта руки | Дополнительная рамка 3 dp Ink |
| Рука | LazyRow без наложения, 70×110 dp × scale, промежутки 8 dp |
| Карты в диалоге пула | 64×100 dp × scale, промежутки 6 dp; число колонок адаптируется к ширине |
| Каталог | LazyVerticalGrid, адаптивная минимальная ширина 96 dp × scale, пропорция 0,7, промежутки 10 dp |
| Служебные кнопки | Область касания от 48 dp |
| Стол в широкой колонке | Не более 560 dp и ограничения доступной высоты ×1,15, минимум расчётного лимита 260 dp |
| Переход к двум колонкам | Внутренняя ширина игровой области >660 dp; стол слева, инструкция/рука/пулы справа |
| Системные области | Один внешний safeDrawingPadding |

При ширине окна 320 dp расчётная ширина клетки `(320 − 24 − 4×5) / 5 = 55,2 dp`; при обычном шрифте стол занимает 240 dp по высоте, при 150% — 355 dp, при 200% — 470 dp. Для ширины 360 dp ширина клетки 63,2 dp, обычная высота стола 273,3 dp. Эти расчёты подтверждают минимум 48 dp в указанных компактных размерах, но не заменяют проверку меньших окон и реальных системных отступов.

В portrait верхняя строка паузы/счёта остаётся над прокручиваемой областью. В неё входят фазовая и учебная инструкции, строка Вилл, стол, панели обоих пулов и рука. В широкой раскладке стол и правая колонка прокручиваются отдельно. Содержимое подробностей, пулов, объявления и результата также прокручивается; нижние действия диалогов остаются доступными.

## Состояния и обратная связь

| Состояние | Видимое поведение |
|---|---|
| Загрузка | Progress и пояснение |
| Ошибка хранения | Явный диалог; принятие команды не обещается до записи |
| Выбранная карта | Толстая рамка, selected и доступное имя зоны/знака/категории |
| Допустимая цель | Светлая рамка; у пустой клетки знак «+»; допустимость задаёт ядро |
| Пулы | Открытые панели обоих игроков с категориями и количествами; касание открывает все собранные карты и комбинации |
| Обучение | Конкретная подсказка, ожидаемая карта руки, ограниченные команды; финальное действие только «Объявить» |
| Старый учебный снимок вне сценария | Объяснение и «Начать обучение заново», без молчаливой замены |
| Ход Вилл | Интервал 800 мс между фазами, затем описание уже принятого открытого действия |
| Объявление/результат | Названия всех учитываемых комбинаций, сумма и итоговый счёт; у результата Вилл используется её открытый пул |

Показатели N/24 для простых, N/3 для треугольника/стихии, N/4 для квадрата, N/5 для пятиугольника/чародеек отражают полный состав группы. Порог очков определяется таблицей правил и показан списком комбинаций, а не знаменателем панели.

Пояснение Вилл — временная строка текущего состояния, без истории скрытых данных. Оно публикуется после принятия и сохранения перехода, привязано к matchId/revision и очищается при паузе, уходе с экрана, новой партии и следующей команде игрока. Задержка не управляет начислением и очередью.

Подсветка реальных карт меняется мгновенно; движения карт и бесконечных анимаций нет. Настройка reducedMotion сохранена, но в действующих MatchScreen/CardCatalog не меняет поведение: 120 мс/snap относятся к прежнему неиспользуемому компоненту галереи. Звук выбора и тактильный отклик в активных экранах учитывают настройки; музыка не добавлена.

## Проверка

Для v0.3 прошли39JVM и все12UI-тестов после окончательных правок на API37: обычныйPixel7 иcompact320dp/font150. Наcompact200 выполнена ручная визуальная проверка инструкции/прокрутки и значков; она не равна полному автоматическому прогону. TalkBack, клавиатура, все ориентации/модели и физический телефон не объявляются проверенными по токенам и расчётам. Текущий результат и ограничения фиксируются в [TEST_CASES.md](TEST_CASES.md).

Обязательные сценарии: обе фазы хода, несколько целей, пустое место, просмотр обоих пулов и отдельной карты, объявление/продолжение, полный учебный маршрут, старый учебный снимок, пауза во время хода Вилл, замена партии, повторное открытие результата и восстановление без повторного эффекта. Скрытые карты руки Вилл и будущий порядок колоды не добавляются в accessibility ради тестов.
